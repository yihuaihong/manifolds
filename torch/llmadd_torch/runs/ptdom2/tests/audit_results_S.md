## 3. 解读（问题 3）

**3a. 比较类（国家、城市、人物；Tier L）：GEOMETRY-SPECIFIC 主要测「正确事实 vs 错误事实」。（重要 1，置信度高）**
- 打乱目标里隐含的答案：用逐 seed 复原的真实置换（item i 的坐标换成 item q[i] 的；答案用 manifold_domains._pair_answer、
  同样的 margin），该 seed 的 held-out 题里，打乱几何仍然给出正确答案的比例：国家 0.453–0.552（均值 0.499），
  人物 0.447–0.568（0.489），城市 0.457–0.537（0.505）。也就是说，打乱先验在 held-out 题上等于灌进一套随机答案；
  它和训练文本里的事实也冲突。
- 数据也支持这一点：打乱臂比同 lr 的 none 差（面积 −10.03 / −0.71 / −13.31，0/8、1/8、0/8 赢，boot90 上界都 < 0）。在训练过的题上，
  城市的 seen final3 也降了（94.5，none 99.5），国家略降（99.25，none 99.72）。打乱臂在 eval 上对真目标的 CKA 被压到 none 以下
  （终态 0.18 / 0.10 / 0.13，none 0.46 / 0.20 / 0.31）。城市打乱臂的面积 72.2 已低于 FLOOR 线 73.6（最好的非几何基线 68.6 + 5），池化难题 final3
  60.4（none@2e-3 为 82.3）。
- 拆解：true − shuffled = (true − none@2e-3) + (none@2e-3 − shuffled)。国家 14.81 = 4.79 + 10.03（68% 来自打乱臂变差），
  城市 16.72 = 3.40 + 13.31（80%），人物 1.93 = 1.21 + 0.71（37%）。
- 剂量匹配在多大程度上成立：λ、位点、窗口、lr 相同；LM 份额差 ≤ 0.01；两臂对各自目标的拟合都很紧（窗口中位 geo 国家 0.013 / 0.017，
  城市 0.014 / 0.015，人物 0.0006 / 0.0006）。打乱臂的先验梯度略大（国家 0.045 对 0.039，城市 0.042 对 0.037），因为它要对抗
  数据里的事实。所以「剂量」匹配的是损失权重和梯度份额，表示被推离 LM 自然几何的距离并不相同。（次要 M5）
- 能推出的：在同剂量下，一个答案错乱的目标不会带来 PASS 那样的增益，反而让读出低于 none。所以 PASS 依赖目标的内容。
  推不出的：(i)「几何作为结构被模型使用」，Tier L 下真目标本身就带着 held-out 题的答案，和「答案经由目标灌入」分不开；
  (ii) true − none 里有多少是几何特异的：shuffled − none = 非特异效应 − 错误内容造成的伤害，两者在这个设计里分不开；
  (iii) 把 +14.8 / +16.7 当成「几何的增益大小」。
- 位置：readout_S.txt:7、:21、:35（阅读行），:8、:22、:36（shuffled − none 行）；readout_ptdom2.py:678–731（阅读条件）。
  核对：floor_shuf.py / floor_shuf.out（置换复原和答案一致率）；extras.out（拆解、seen final3、梯度）。

**3b. 月份（k 步；shuffled ≈ none）能说明什么，FLOOR 限制了什么。（重要 2，置信度高）**
- 打乱圆环隐含的「x 之后第 k 个月」答案，正确率 1.9–13.2%（均值 8.3%，就是机会水平）。
- 但 none 本身在 tier S 的 held 读出上就几乎为 0：面积 0.74 / 0.76，final3 0.26 / 0.35，机会 8.3。原因是系统性地偏离答案
  （seen ≈ 100%，held 远低于机会，是拉丁方 held-out 设计下「记住训练答案」的典型表现）。所以打乱臂没有往下掉的空间，
  shuffled − none 的窄区间 [−0.18, +0.13] 是地板造成的，不是「打乱目标无害」的证据。A5c / A5d 对月份「通过」没有信息量；
  如果只看 A3.2 / A4 / A5 的其他条件，月份会被印上「the gain depends on the correct geometry」，挡住它的只有 FLOOR 一条
  （compare_S.out：without FLOOR → True）。
- 月份真正显示的：真圆环先验让 tier S 的 held 读出从约 0.7% 升到 5.0%（面积），70% 在窗口内；终态 final3 1.77 对 0.26，
  仍远低于机会。也就是在机会水平以下暂时少犯系统性错误。月份 12 个条目都是单 token，先验的位点就是 k 路候选自己的输出行
  （tied embedding），所以这也分不清「模型用了几何」和「几何被写进输出行」。
- 描述性，未预注册：tier E（40 题，读出在机会以上）上 true − shuffled +8.1 [−0.8, +16.6]（6/8），true − none@4e-3
  +0.9 [−3.8, +5.6]，shuffled − none@2e-3 −2.4 [−8.7, +4.0]。在能测到的那一层，看不到对 none 的增益，也排除不了打乱目标有害。
  这只用来说明 tier S 的「shuffled ≈ none」不能外推，不进任何判词。

**3c. 城市 final3 区间下界 < 0 的含义。（重要 3，置信度高）**
- final3 vs none@4e-3：+2.78，boot90 [−0.60, +6.03]，6/8，双侧 p .235（逐 seed 有 −8.04 和 −0.14）。到训练结束，对 F100 所选
  none 的增益没有被证明。面积 PASS 有一半来自窗口内（26/75 次 eval 贡献 +2.07 / +4.12），是「学得更快」的形状，和 F100 审查第 3 条一致。
- 对同 lr 的 none@2e-3，final3 +1.96 [+0.25, +3.69]（7/8）。这不是预注册的对比，只能作描述。在全新 seed 上 none@2e-3 的面积（85.50）
  还略高于 F100 选的 none@4e-3（84.78）。
- 难题子集 vs none：+6.52 [−2.39, +15.18]，p .29。F100 是 +0.1，这里点估计变大，但不显著，不能写「难题上更好」。
- vs shuffled 的 final3（+13.1，下界 +8.9）很稳，原因是打乱臂的伤害一直持续到训练结束（打乱臂 final3 79.6，none 90.7），不是真臂终态变好了。

  所以 F100 那条「后半全正」的类比条件城市过不了。写「复现」时要写明是哪套规则。

## 5. FINDINGS 能写 / 不得写（遵守 AUDIT.md:720–729 的 A5 决定）

  和 GEOMETRY-SPECIFIC 的判词，加 FLOOR 和机会水平以下的说明，不写几何依赖。

**能写**（数字都来自 readout_S.txt，已独立核实）：
1. 「F100 的 4 个 PASS 在全新 seed 8–15 上按 ptdom2 预注册规则全部复现（同一对比：only-d@2e-3 vs F100 选的 none lr；88 个 run 全部有效）：

   打乱目标在 held-out 题上隐含的答案约一半正确（Tier L：打乱先验相当于灌入错误事实）。（建议，非必需：(ii) 的原文是对的，但读者可能低估这个伤害。）
4. 「同剂量但答案错乱的先验带不来这个增益，反而让读出低于 none」：这是纯数据描述，可以写。
5. 国家：「增益持续到训练结束（final3 +3.7 [+2.1, +5.7]，8/8），集中在难题子集（+8.7 [+5.1, +13.1]，8/8）」，与 F100 一致。

**不得写**：
1. 任何一个领域写「the gain needs / depends on the correct geometry」「增益依赖正确的几何」（(i) 不满足或 A5 判 UNDETERMINED；月份是 FLOOR）。

5. 「打乱目标对月份无害 / 中性」：这是地板效应。
6. 月份终态变好、高于机会、几何依赖；也不能用月份 final3 和 F100 比符号。
7. 城市终态更好、城市难题子集更好。
8. 「对 none 的最优 lr 也成立」（B1 的 none 只在 2e-3 上跑过）；「4 次独立确认」。
9. F100「不得写」的其余各条照旧有效（例如「这 4 个流形先验在 53M 预训练里都有帮助」）。
