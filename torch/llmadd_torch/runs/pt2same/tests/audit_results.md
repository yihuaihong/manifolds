**I2. SHOWN 处在边缘：预注册的百分位 bootstrap 在 n = 8 时偏窄，其他常用区间都含 0**
- **位置：** readout_pt2same.py:118–137（百分位 bootstrap）；AUDIT.md:108–117。
- **事实（描述性，不改判词）：**
  - 8 个逐 seed 斜率（同一个 seed 在各尺寸共用数据流和留出题，与联合 bootstrap 的配对单位相同）是 +0.92 +0.24 +2.73 +3.45 +0.31 +1.10 **−2.21** +4.93，7/8 为正。
  - 对这 8 个值做 t 区间（df 7）：90% 是 **[−0.05, +2.92]**，双侧 p = .109。精确 sign-flip p 也是 .109。
  - 各尺寸当作独立样本的 Welch 近似：[−0.06, +2.93]。各尺寸独立重抽的 bootstrap：[+0.10, +2.70]。
  - 百分位 bootstrap 用的是 √((n−1)/n) 缩小的 SE 和正态分位（1.645，t₇ 是 1.895），名义 90% 的实际覆盖率大约 85%。
  - 留一 seed：点斜率在 +0.94 到 +1.96 之间，都为正。但去掉 seed 2、3 或 7 中的任何一个，联合 bootstrap 的 5% 分位就变成负的（−0.08 / −0.11 / −0.13）。
- **为什么会写错：** 「90% CI 排除 0」容易被写成「显著」「确定随尺寸增长」。规则只要求方向，判词有效。但它的强度大约相当于双侧 p ≈ .1，不是稳健结论。
- **检查：** recompute.log 的「CI robustness」一节。
- **置信度：** 高。

**I6. 53M none 的 winner's curse 让斜率偏正，而不是 A1 第 2 条说的偏负；LOSO ≈ 0 不说明趋势是假的**
- **位置：** AUDIT.md:188–192（A1 第 2 条：「biases the slope NEGATIVE」）、:240–244（LOSO）、:277（A3 第 3 条）；readout_a1.txt 的 (d) 节。
- **事实：**
  - 53M none@8e-3 的两半：Torch 22.79 / 18.39，Burst 23.10 / 13.77。
    - Torch 的 seed 0–3 用的 init 和数据与 Burst 选 lr 用的 seed 0–3 相同。这一半偏高，就会压低 Δ53 的 0–3 值（45.99 对 49.99），抬高 0–3 的斜率（+1.84 对 +1.03）。
    - 所以选择效应的方向是**偏正**。
    - A1 第 2 条说偏负，那是另一个机制（换站点挪动了最优 lr）。A1 的敏感性在 Torch 上仍选 8e-3，没有看到这个机制。
    - 4.4 点的两半差约等于 1 个 SE（4 对 4、SD 约 6 时 SE 约 4.2），curse 和噪声分不开。
  - 不受选择影响的 seed 4–7 斜率是 +1.03（点估计）。
  - 505M 和 190M 的 pick 都是按 bpb 打破并列选出的（没有直接取面积最大），seed 0–3 的 curse 很小或方向相反：505M none 24.70 / 24.19，190M none 26.84 / 29.13。
  - LOSO 的 17.05 是**有负偏差的估计**：
    - 三个 lr 几乎并列，逐 seed 的 SD 很大：4e-3 是 10.5，8e-3 是 4.3，1.6e-2 是 6.7。
    - bpb 的并列打破永远选最低的 lr 4e-3。
    - fold 0 和 fold 3 留出的 seed 0、3，正好是 4e-3 下面积最低的两个（12.48 / 10.91）。拿掉它们以后 4e-3 和 8e-3 并列，于是选中 4e-3，再拿这两个 seed 在 4e-3 的低值去评估。这就是少 seed、选项并列时 LOSO 的典型负偏差。
  - 53M none 换成其他合理取值时，seed 0–3 的斜率：
    - LOSO：+0.02；

## 5. 解读层面最容易写错的地方（逐项回答第 4 问）

1. **哪一臂**：先验 arm（见 I1）。53M→190M 是先验在三位数 bucket 上变好；190M→505M 是 none 下降、先验持平。不得照抄 A1 第 4 条或 F97 FIXSLOPE 的「来自 none」。

4. **LOSO 把 seed 0–3 斜率降到约 0**：
   - 这个数有负偏差（选项并列、逐 seed 方差大、bpb 并列永远选 4e-3）；
