    面积约 90 的上限由 t50 约 2000 万 token 决定，所以先验在天花板附近，看不出它自己是否随尺寸变强。
  - none 的 t50 中位数 88.7 / 100.0 / 87.7 / 104.9 / 109.5 / 124.2M，最后一次 eval 94.7 / 95.9 / 98.5 / 96.9 / 96.0 / 92.4。
  - token 数固定（3 亿）时，ln tpp = ln T − ln N，所以对 ln N 的斜率恒等于对 ln tpp 斜率的相反数（tpp 21.2 / 7.15 / 2.65 /
    1.43 / 0.745 / 0.318）。
  - 先验的 LM 占比（I3）与 ln N 的相关是 0.96。
  - 本设计分不开「尺寸」「训练充分度（none 欠训练）」和「先验剂量」。
- 置信度：高。
