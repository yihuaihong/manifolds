**S1: reproduces, write as is**
- **Against the window run** (final3): dim +12.25, torus +9.40, box5 +38.49, 8/8 each. The worst seed is still +2.8 / +3.8 / +24.6.
- **Against the per-seed oracle** (best of 6 none lrs per seed): +31.36 / +35.19 / +2.47 / +2.13 / +4.13 / +33.16, all 8/8. The worst seed is ≥ +0.64.
- **"Best on all six"** holds by 8-seed mean over every arm and lr (including all6@2e-3, all4 and only-m), with these margins:
  - countries is only +0.28 [−0.27, +0.82] above the runner-up all6@2e-3 (5/8), so it is effectively a tie;
  - numbers is +0.64 above window (7/8);
  - cities is +0.95 above all4 (7/8).
  - Write it as "highest mean on all six".
- **Device is not the cause.** The two all6full seeds on B200 (s16, s20) go the same way with similar size: dim +7.5 / +28.7, torus +15.9 / +11.2, box5 +32.9 / +60.0.

**S2: numbers reproduce, wording must change**
- **Numbers:**
  - all6full 1.2112;
  - none@2e-3 1.2098 (+0.111%);
  - per-seed best none lr 1.2065 (+0.385%; the best lr is 2e-3 in 7/8 seeds);
  - window 1.2133.
- **Problem 1:** the 95% CI of the difference to the per-seed best none goes up to +0.86%, so "at most" does not hold.
- **Problem 2:** at the same lr, all6full is −0.18% against the window run (lower in 6/8 seeds). Keeping the priors on to the end costs no bpb by itself.
- **Suggested sentence:** "Final bpb 1.2112: +0.1% against no prior at its bpb-best lr 2e-3 (1.2098), +0.4% against the per-seed best no-prior lr (1.2065), and below the window run (1.2133)."
- **Scope:** none's bpb optimum sits at the lower edge of the grid (2e-3); none@1e-3 was not run.

**S3: reproduces, can be written stronger**
- **Numbers:**
  - h4 (all4 − only-dim) +1.49 [−4.78, +7.77], 5/8;
  - h6 (all6 − only-dim) +13.50 [+7.37, +19.63], 8/8;
  - all6 − all4: area +12.01 [+3.82, +20.20], final3 +22.01 [+8.56, +35.46], both 7/8; paired t p 0.010 / 0.006, Wilcoxon p 0.016.
- **The only reversal is s23** (−10.8 / −14.7). That seed's own h6 is the weakest (+2.7 / +0.0), and its registered run was on A100. Do not drop it. Without it the result is +15.3, 7/7 (for reference only).
- **The device confound can be ruled out.** all4 ran on A100 / H100 while the comparison runs ran on B200. The V5 re-draws bound the effect of device and re-draw:
  - all6@2e-3 s17 re-drawn on H100 gives dim area 78.6 (registered B200 80.7; all4 at the same seed 68.5);
  - s16 re-drawn on B200 gives 89.0 (registered 86.3; all4 69.1);
  - so re-draw noise is about ±3, which cannot explain 12 points.
- **"Needs these two priors" vs "needs more prior gradient".** The total prior gradient is 0.095 in all4 against 0.143 in all6 (no clipping), and V4 alone does not separate the two explanations.
  - But pt6comb also has 6 priors, with only torus / box5 swapped for S4 / people, and its h is +1.6 [−4.4, +7.6], the same as all4.
  - So two independent lines of evidence point to the torus and box5 priors themselves. One can add half a sentence: "as in pt6comb, where swapping them for S4/people gave +1.6".

**S4: numbers reproduce, wording is wrong**
- **Numbers:** all6 − all4 (area / final3) is numbers +0.36 / +0.24, cities +0.42 / −0.02, countries +0.22 / +0.40. All CIs are within ±1.9. This supports "removing torus/box5 does not affect these three".
- **It does not support "gain nothing from the joint setting":**
  - cities: h6 +1.72 (6/8), h4 +1.30 (7/8);
  - countries: h6 +1.22 [+0.03, +2.40] (6/8), h4 +0.99;
  - numbers: h6 −0.51, positive in only 1/8.
- **Suggested sentence:** "Removing the torus and box5 priors leaves numbers, cities and countries unchanged (all6 − all4 ≤ 0.4 point, area and final3); cities and countries still gain 1–2 area points from the joint setting with or without them (h6 +1.7 / +1.2, h4 +1.3 / +1.0), numbers none (h6 −0.5)."

**Possibly missed true effects**
- Two items S1 does not mention: with priors on to the end, numbers area +2.25 [+1.6, +2.9] (8/8) and cities final3 +1.47 (7/8).
- "Gain nothing" in S4 erases the small joint gain of cities / countries.

**Summary**
- **Most likely mis-measurement:** S4 writes "all6 − all4 ≈ 0" as "the joint setting has no gain". Yet cities and countries have h of +1 to +1.7 area points, and the countries h6 CI excludes 0.
- **True effects that may be measured or written away:**
  - S4's "gain nothing" erases the cities / countries joint gain;
  - S2's "costs" framing leaves out that bpb is lower than the window run (−0.18%, 6/8);
  - S3 does not use pt6comb to rule out the "number of priors" explanation;
  - S1 does not mention numbers area +2.3 (8/8).
- **Strongest supported statement.** In the pt6v2 setting (52M model, 18310 steps, seeds 16–23, mixed devices):
  - With six priors kept on to the end (lr 1e-3), end-of-training held-out accuracy is dim 96.5 / torus 99.8 / box5 91.4.
  - That is +12.3 / +9.4 / +38.5 above the window run (8/8), and above the per-seed best no-prior lr on all six manifolds in 8/8 seeds (+31.4 / +35.2 / +2.5 / +2.1 / +4.1 / +33.2).
  - bpb is below the window run and only +0.1% above no prior at 2e-3.
  - At lr 2e-3, removing the torus and box5 priors removes nine tenths of the joint gain on dim (area +12.0 of +13.5, final3 +22.0, 7/8), and pt6comb shows the same; numbers, cities and countries change by ≤ 0.4.
  - Against this, S2 is weaker than the evidence, S3 is also on the weak side (it does not use pt6comb), and S4 overstates on "no gain".
